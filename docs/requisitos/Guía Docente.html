La idea, como una dirección postal

Una IP tiene dos partes: el barrio (la red) y la casa (el host). El prefijo (/24, /26…) es la línea que separa el barrio de la casa. Subnetear es partir un barrio grande en varios más pequeños, cada uno con sus casas.

2. Aprende con un ejemplo (paso a paso)

Resolvamos juntos 192.168.10.0/26. Sigue el razonamiento y luego repítelo tú en la calculadora de más abajo.

  1. ¿Cuántos bits son de red y de host? El /26 significa 26 bits de red y 32 − 26 = 6 bits de host. Con esos 6 bits se cuentan los equipos.
  2. La máscara. 26 unos seguidos dan 255.255.255.192. (El último octeto, 11000000, vale 192.)
  3. El "tamaño de bloque". Con 6 bits de host: 2⁶ = 64. Las subredes van de 64 en 64: .0, .64, .128, .192.
  4. La subred donde cae .0. Su dirección de red es 192.168.10.0; la siguiente empieza en .64, así que el broadcast es 192.168.10.63.
  5. Hosts utilizables. Del .1 al .62 → 62 hosts (2⁶ − 2, porque la red y el broadcast no se asignan a equipos).

Regla rápida: bloque = 2^(bits de host). La red es el inicio del bloque y el broadcast es el número justo antes del siguiente bloque.

    Habla el idioma

    Glosario

    WAN
    Red de área amplia: conecta redes distantes (entre sedes/ciudades). LAN es la red local de un sitio.
    Subnetting
    Dividir una red en subredes más pequeñas para organizar y aprovechar mejor las direcciones IP.
    Prefijo / máscara (/24)
    Cuántos bits de la IP son de red. El resto son para los hosts (equipos).
    Dirección de red / broadcast
    Red: la primera de la subred (la identifica). Broadcast: la última (habla con todos).
    IP pública / privada
    Pública: visible en Internet. Privada: solo dentro de tu red (10.x, 172.16–31.x, 192.168.x).
    Topología
    El mapa de la red: qué dispositivos hay, sus roles y cómo se conectan.
    Cisco IOS / Huawei VRP / FortiOS / RouterOS
    Los sistemas y sintaxis de configuración de Cisco, Huawei, Fortinet y MikroTik.
    VLAN / NAT / DHCP
    VLAN separa el tráfico; NAT traduce privadas a pública; DHCP asigna IPs automáticamente.
    SSH / Telnet / VPN
    Formas de conectarse a equipos (SSH cifrado, Telnet no) y túnel cifrado entre redes (VPN).
    Prompt injection
    Ataque donde se esconden instrucciones para que una IA las obedezca sin que lo notes.
    Prueba (test) / % de confianza
    Comprobación automática de que algo funciona. El % es cuántas pruebas pasan (18/20 = 90%).
    Commit / rama / Pull Request
    Guardado con etiqueta / línea de trabajo aparte / propuesta para unir una rama a la principal.
    Sustentación
    Presentar y defender el trabajo en vivo, mostrando que funciona y explicando cómo.
